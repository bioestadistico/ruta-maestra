# Plan de análisis de datos

El plan de análisis de datos articula el nivel investigativo, los objetivos y las variables o categorías del estudio mediante una especificación prospectiva. Define procedimientos, salidas y criterios de interpretación para elaborar los resultados con los datos recolectados.

## INSUMOS

**Productos anteriores.** Recupera el proyecto vigente y conserva la correspondencia entre objetivos, variables o categorías, diseño y población, junto con las hipótesis, muestra e instrumentos cuando correspondan; utiliza las decisiones analíticas aprobadas y separa únicamente los asuntos pendientes.


Usar como insumo principal el proyecto de investigación o su equivalente, en la versión disponible hasta esta etapa de la Ruta Maestra. Extraer de su contenido el enunciado, nivel investigativo, objetivos, diseño, población y contexto, junto con el cuadro de variables y la muestra cuando correspondan.

Recuperar las categorías disponibles y la información necesaria para planificar el análisis cualitativo. Solicitar solo el dato que no conste o sea insuficiente para tomar una decisión analítica válida.

Nivel investigativo y objetivos: Recuperar el nivel investigativo, los objetivos y la intención analítica de cada uno, cuando esté disponible.

Variables o categorías y diseño: Recuperar las variables cuantitativas o el fenómeno y las categorías cualitativas disponibles, el diseño y la unidad de análisis del proyecto. Precisar dependencia en mediciones cuantitativas y contexto de las fuentes en la ruta cualitativa.

Decisiones analíticas disponibles: Recuperar el estimando o contraste y las condiciones conocidas que puedan afectar la decisión, como datos faltantes, ponderaciones, conglomeración, estratificación, confusión, interacción o multiplicidad. Utilizar lo previamente definido; lo pendiente se resolverá durante la operación, sin exigirlo como requisito de entrada.

## PROCESAMIENTO


1. Evaluar la correspondencia entre el nivel investigativo, los objetivos y las intenciones analíticas recuperadas; identificar las que estén pendientes. Usar el nivel investigativo como regla principal para orientar el tipo de análisis previsto.

   Contrastar para cada análisis la información recuperada en Variables o categorías y diseño y Decisiones analíticas disponibles. Definir lo pendiente y resolver las incompatibilidades que afecten la decisión analítica.
2. Seleccionar provisionalmente el procedimiento compatible, sus supuestos y una alternativa razonable cuando corresponda. Organizar las decisiones en una tabla de intenciones analíticas cuando ayude a mantener la trazabilidad entre objetivos y análisis, sin sustituir la justificación de cada elección.
3. Redactar el plan en futuro, sin incluir resultados, valores p, intervalos calculados ni conclusiones. Presentar al investigador las decisiones que afecten el alcance o la interpretación del estudio y registrar su aprobación antes de cerrar el plan.

### Rutas orientativas de planificación

Usar las siguientes rutas como criterios de planificación. Elegir el procedimiento previsto según el objetivo, estimando, diseño, tipo de variable, dependencia y supuestos.

**Nivel exploratorio**. Planificar un enfoque cualitativo compatible con la pregunta, el diseño, el tipo de datos y la postura epistemológica, como análisis temático, de contenido, del discurso, fenomenología, etnografía o estudio de caso.

**Nivel descriptivo**. Para describir o caracterizar, prever frecuencias para variables categóricas y medidas de tendencia central y dispersión para variables numéricas. Para estimar o contrastar, definir el parámetro, el intervalo de confianza o el procedimiento de contraste que corresponda.

**Nivel relacional**. Para comparar, asociar o correlacionar, prever una prueba o modelo compatible con el tipo de resultado y el diseño. Distinguir explícitamente la comparación de grupos independientes de la comparación de medidas pareadas o repetidas.

Cuando corresponda, planificar la medida de efecto o asociación, como diferencia, razón, odds ratio, riesgo relativo, razón de prevalencias o coeficiente de correlación.

**Nivel explicativo**. Planificar un modelo multivariable acorde con el desenlace, diseño y pregunta causal. Definir confusores, interacciones, control de sesgos, diagnóstico y análisis de sensibilidad. La interpretación causal requiere un diseño y supuestos causales defendibles, además de temporalidad adecuada.

**Nivel predictivo**. Distinguir la intención de predecir un desenlace, pronosticar el tiempo hasta un evento o proyectar una medida en el tiempo. Planificar un modelo compatible con esa intención y definir predictores, remuestreo o partición, validación, calibración, discriminación, error de predicción, riesgo de sobreajuste y utilidad prevista.

**Nivel aplicativo**. Planificar la metodología analítica que responda al objetivo de mejora, control o aplicación, como control estadístico de procesos, DMAIC o CRISP-DM cuando resulte pertinente.


## PRODUCTO

### Producto provisional

Presentar la tabla de intenciones analíticas con las columnas objetivos, variables o categorías, procedimiento propuesto y salida. Después, redactar el plan en futuro, comenzando directamente con el primer objetivo secundario y siguiendo el orden aprobado de los secundarios, sin preámbulos.

Integrar objetivos que compartan procedimiento solo cuando se conserven su trazabilidad y diferencias relevantes. Gestionar el cierre y las decisiones mediante la [revisión y aprobación de productos](od-01-revision-y-aprobacion-de-productos.md).

#### Especificación del capítulo de resultados

Para cada objetivo cuantitativo, definir la salida que se producirá posteriormente con el proyecto y la base de datos verificable:

Tabla o gráfico previsto, con título, variables, categorías, unidades y estadísticos.
Procedimiento, prueba o modelo, con sus supuestos y alternativa.
Estadístico, estimación, intervalo, medida de efecto o indicador de desempeño.
Criterio de interpretación compatible con el objetivo y el diseño.
Párrafo previsto con el hallazgo numérico, su interpretación técnica y la remisión a la tabla o figura, sin discutir causas ni literatura.

### Producto final

El producto final es el **Plan de análisis de datos**. Conservar la narración aprobada en futuro, con la apertura directa y el orden de los objetivos secundarios establecidos para el producto provisional, sin preámbulos, tabla de intenciones ni apoyos de revisión. Aplicar las reglas de la [revisión y aprobación de productos](od-01-revision-y-aprobacion-de-productos.md) y de la [presentación y entrega de productos](od-02-presentacion-y-entrega-de-productos.md) para cierre y preservación literal.
